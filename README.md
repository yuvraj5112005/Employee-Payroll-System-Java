# Employee Payroll System 💼

A Java-based Employee Payroll System developed using Object-Oriented Programming (OOPs) concepts.
This project manages employee records and calculates salaries for full-time and part-time employees.

## Features

* Add Employees
* Remove Employees
* Display Employee Details
* Salary Calculation
* Full-Time Employee Support
* Part-Time Employee Support

## Technologies Used

* Java
* OOPs Concepts
* ArrayList
* Method Overriding

## OOPs Concepts Used

* Abstraction
* Inheritance
* Polymorphism
* Encapsulation

## How to Run

1. Open the project in VS Code
2. Compile:
   javac src/Main.java
3. Run:
   java -cp src Main
